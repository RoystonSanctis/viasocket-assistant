Privacy

SOCKET talks to the AI provider you chose, using your key. Here is what that means in plain words.

Sent to your AI provider

  • The messages you type or say to SOCKET.
  • The structure of the flow or plug you are working on: step names, step settings, field mappings and code.
  • The short error message viaSocket shows when a save, test or publish fails. With Strip run data on, it is masked like the error text described below.
  • Results of test runs and past runs, in the reduced form described below.

Run data

Run data is what passed through a flow or plug: test outputs, sample data, inputs, variables and logs. With Strip run data on (the default, set by the stripRunData flag in the public config), SOCKET sends this instead of the data itself:

  • The structure and field names, so SOCKET can map fields by their path. Field names that look like data (containing an @ or a long number) become <key>.
  • The shape of each value instead of the value, such as <email>, <phone>, <number>, <date>, <url>, <digits:10> or <string:12> (text 12 characters long). True, false and empty values are sent as they are.
  • Error and console text from runs, with emails, phone numbers, long numbers, tokens and longer quoted values replaced by placeholders such as <email> or <token>. The rest of the wording is sent, because it is needed to fix the problem, so anything else written into an error or log line can still reach the provider.
  • Long lists and deep objects are cut to their first few entries.

If the config turns stripping off, run data is sent as it is, only shortened to fit.

Kept back

  • Your viaSocket login stays in your browser. The AI provider never sees it.
  • With on-device Whisper, your voice stays on this computer. Only the transcribed text is sent.

Worth knowing

  • Free tiers and free models may log your prompts or use them for training. Check your provider's policy, or use a paid or local model for sensitive work.
  • Nothing is sent to the people who make this extension. There is no analytics or tracking.
